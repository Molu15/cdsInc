# cdsInc.

We present to you cds Inc., a mobile application all about cats with fun minigames. Players scan images in the real world with their phone camera (AR image tracking) to unlock the minigames.

The app was created as a team project in the Master's program User Experience Design (M.Sc.) at Technische Hochschule Ingolstadt, built in Unity.

## Getting started

To get started, you have 2 options:

1. Download the APK file (`cdsFinal.apk`) and start the game directly on an Android device.
2. Download the Unity project and build it from there.

## Minigames

- **Toy Hunt**
- **Flappy Cat**, controlled by tilting the phone

## Design process

We planned the app with user flows and UML diagrams and started with low-fidelity wireframes. We then ran two usability tests with three participants each, using observation and the HARUS questionnaire.

The tests showed an unclear onboarding, missing progress feedback and uncertainty about how to scan. We added help and explanation panels, feedback messages, progress counters and sound cues. We also tested face tracking as an input method and replaced it with tilt control. In the second test round, all participants completed all three minigames without external guidance.
